# 链动小铺商家增强工具·改

用于链动小铺商家后台（`wzyp.cn` / `ldxp.cn`）的油猴脚本，包含货源广场筛选对接与商品列表批量修改两个面板。

## 功能

### 货源广场
- **筛选**：按关键词、结果内二次关键词、供货商、价格区间、上架状态、库存、对接状态、是否排除 0 元商品、是否仅看店内热销进行过滤。
- **商家条件与排序**：按供货商保证金、实名状态过滤；支持按成本、店铺总销量、保证金、店内热销、单品销量或默认顺序排序。
- **统计与快捷过滤**：显示当前结果的商家数、有保证金商家数和成本范围；生成价格区间与标题高频词按钮，点击可过滤当前列表。
- **商品详情与对接**：在右侧抽屉查看商品图、售价、市场价、对接成本、供货商信息（实名、保证金、地区、开店时间、QQ）及商品说明；支持单条或勾选批量对接。
- **请求限速与缓存**：请求间隔 800~1100ms、每分钟最多 35 次、每满 20 次暂停 4.5 秒，返回 520/444/429 时暂停请求 120 秒；已查过的店铺与商品信息保存在当前会话 `sessionStorage` 中避免重复请求。

### 商品管理
- **筛选与排序**：按商品名称、类型、上架状态、分类、库存、是否排除 0 元过滤，支持按销量或价格排序。
- **批量修改与导出文本**：批量修改分类、售价（固定价 / 按比例 / 加减金额）和上下架状态；按所选商品生成名称、库存、价格、链接文本并复制到剪贴板。

## 安装

1. 浏览器安装 Tampermonkey 或 Violentmonkey。
2. 点击 [直装链接（Raw）](https://raw.githubusercontent.com/AsabaLazy/ldxp-merchant-toolkit-mod/main/ldxp-merchant-toolkit.user.js)，或在仓库打开 [`ldxp-merchant-toolkit.user.js`](./ldxp-merchant-toolkit.user.js) 点击 Raw 安装。
3. 登录链动小铺商家后台并刷新页面。
